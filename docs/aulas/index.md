# Aulas

Planos de 50 minutos, pensados pra quem vai dar aula (professor,
monitor, quem tá organizando uma oficina). Cada um segue a mesma
estrutura: objetivo, pré-requisitos, roteiro minuto a minuto, falhas
comuns e o que fazer com elas, exercício de fechamento, e uma rubrica
simples de "deu certo?".

- [Aula 1 — Primeiro contato](aula-01-primeiro-contato.md): instalar,
  conectar (ou usar sem robô), primeiro comando
- [Aula 2 — Sensores](aula-02-sensores.md): calibrar e ler sensor em loop
- [Aula 3 — Seguir linha](aula-03-seguir-linha.md): bang-bang de verdade

Pré-requisito comum a todas: aluno já sabe o básico de Python (variável,
`if`, `while`, função) — essas aulas não ensinam Python, ensinam
robótica usando Python.

Cada aula termina apontando pro nível correspondente em
[Atividades](../atividades.md), pra quem terminar antes ou quiser
praticar em casa.
